# Streamer Options – Discord Bot

This repository contains the official Discord bot for [Streamer Options](https://github.com/Qetrox/streameroptions-expressjs).  
It allowed discord server to get notifications when streamers registered on Streamer Options went live.

## ✨ Features

- View point and watchtime leaderboards
- Add live notifications to a channel

## 🛠 Tech Stack

- Node.js
- discord.js for bot interactions
- Websocket to communicate with the Streamer Options webserver which sends all twitch events to the bot.
